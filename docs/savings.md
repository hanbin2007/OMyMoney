# 存钱计划口径

存钱计划是本地进度记录，不是银行余额或资金冻结功能。四种模式为固定金额、递增、倒序递减和自定义目标。固定、递增和倒序支持 1 至 1000 期，按日、周、月、年及间隔安排；季度可用每三个月表示。自定义模式仅保存目标和可选结束日期，不生成虚构的定期存款。

金额使用币种最小单位，不经浮点计算。倒序金额最低为零；计划总额必须在受支持的金额范围内。月份和年度始终从原始日期计算，月底及闰日不会逐期漂移。累计入金可超过目标，实际累计和超额完整显示，进度条最高为 100%。

## 两种入金

- 仅记录：指定日期、金额和备注，只改变计划进度，不生成收入、支出或转账。
- 关联已有转账：引用同一账本中的普通转账，以实际转入本金计入计划，不再次操作余额。转入币种必须与计划相同；跨币种转账使用保存的实际转入金额，不使用最新汇率重算。

一个转账只能分配给一个入金记录，不能跨计划重复计数。转账后续被修改时，进度跟随当前有效金额；被删除、改为其他类型或改为不同币种时，该记录保留并显示关联异常，不继续计入进度。恢复有效转账后重新计入。撤销入金、删除计划只删除进度记录，不删除或撤销关联转账。

编辑时，两种模式的日期分别保留。关联模式采用转账日期，不校验当前不可见的手工日期；切回仅记录模式仍保留尚未修正的原始输入。失效历史关联可以更正备注，日期保留原合法记录。

暂停计划后不能新增入金，但仍可更正、撤销已有记录。恢复不会自动扣款或生成入金。目标可以调整；已有记录时不能改变计划币种。排序持久保存，编辑与删除均检查记录版本，存储失败整笔回滚。完整备份保存计划、排序、记录及转账引用。

## 原版对照

静态参照包括原 APK 的 `SavingPlan`、`SavingTransaction`、`FixedAmountDepositRule`、`AbstractIncreasingDepositRule`、`ReverseWeekly52DepositRule`、`Monthly12DepositRule` 与 `CustomDepositRule`。原版自定义为目标和日期范围，倒序规则将负值截为零。此处仅使用业务行为作参照，未复制其代码；原版界面和服务端执行状态不据此宣称已核实。

本地版将固定期数方案归为可配置模式，而非逐个复制预设页面。月份采用锚点计算，不沿用可导致月底漂移的逐次日期推进。现有转账不可部分分摊到多个计划；需要独立分配时应使用明确的多笔转账或仅记录模式，而不是隐藏地重复计账。
