# 本地资产与借贷

本地版独立实现。静态对照原版 `LoanPayAct` 的本金与利息输入及分开保存、`CreditInfo` 的每月账单日/还款日或账单日后天数、`AssetDiffAct` 的调整原因。未复制源码，未连接原同步、债务结清或银行接口，不能据此确认服务端的完整规则。

| 业务 | 本地分录 | 普通收支 |
| --- | --- | --- |
| 借入本金 | 负债账户减少，到账账户增加 | 不计收入 |
| 借出本金 | 付款账户减少，应收款账户增加 | 不计支出 |
| 归还本金 | 付款账户减少，负债账户增加 | 不计支出 |
| 收回本金 | 应收款账户减少，到账账户增加 | 不计收入 |
| 借款利息 | 付款账户减少，关联原借入记录 | 独立利息支出 |
| 出借利息 | 到账账户增加，关联原借出记录 | 独立利息收入 |
| 信用卡消费 | 信用卡余额减少 | 普通支出 |
| 信用卡还款 | 付款账户减少，信用卡余额增加 | 转移资金，不重复计消费 |
| 余额调整 | 指定账户按增加/减少方向改变 | 不计收支与预算 |

负债余额为负数；应收款余额为正数。未结清本金按借贷来源减去已结算本金计算，不包含期初余额、手动调整或利息。账户详情分别显示当前余额、期初余额、未结清本金、累计利息和全部账本的流水，避免把这些数混为同一个指标。统计与预算在 C4/C5 消费相同类型口径。

每笔本金结算关联一笔原记录，须在同一本账本、同一币种，且保留原本金账户；编辑器固定该本金账户，现金收付账户可以不同。新增结算需要先恢复已归档的本金账户。累计结算不能超过原本金，利息不会悄悄转成本金。修改来源、删除或撤销均重新检查关联约束。已有交易历史的账户不能更改类型或期初余额；归档不删除历史，历史账单仍可编辑及撤销。

信用卡周期仅由用户输入计算，月份中不存在的日期取当月最后一天。详情显示最近已出账周期；每月固定还款日取账单日之后第一次符合的日期，或按账单日起 1–90 个自然日计算。信用额度可选，不强行阻止余额超额。实际银行到期日、最低还款额、共享额度、利息计提和入账日不由本地数据猜测，银行账单为准。

资产分组是账户元数据，不单独保存空分组；可以在账户编辑页填写分组。分组顺序由其中第一项的持久化顺序决定，分组排序保留内部账户顺序，分组重命名原子地更新归档成员。账户和分组顺序随备份保存。

余额调整输入差额而不是目标余额，必须填写原因，保存到明确显示的账本。取消不产生记录；保存后可从账户流水进入详情编辑或删除。调整不会重写期初余额，也不会丢失修改来源。

账户流水金额显示当前账户的实际分录及正负号，不借用普通收支列表的符号。因此一笔转账在付款账户为负数、到账账户为正数，余额调整的增减也能直接辨认。周期与调整表单校验会保留输入、标出具体错误并定位对应字段；周期开关的名称与状态作为一个可访问控件提供。

余额调整对话框显式处理系统栏和输入法边距，避免放大字体后聚焦错误字段把确认按钮推入键盘后方。边距处理遵循 [Android Compose Window Insets](https://developer.android.com/develop/ui/compose/system/insets-ui)；除 Compose 表单断言外，验收检查原生无障碍窗口坐标与输入法窗口是否相交。

## 多币种与历史

手动汇率为有方向的币种对，并带用户确认的日期；不会联网更新，也不会自动猜测倒数或交叉汇率。设置中的未归档账户折算使用当前手动汇率，不是历史市场价值。任一非零币种余额缺少到基准币的汇率时，只显示缺失币种，不提供伪造的合计。零余额无需汇率。

每笔账单保留业务名义金额，以及至多一个外币结算账户的实际金额、当时汇率与日期。转账的名义币种为转出账户币种；借贷的名义币种始终为本金账户币种；退款、报销回款、本金结算和利息维持原来源币种，用它计算关联上限。实际现金收付可以是外币。选择外币现金账户不会直接把已识别的人民币数字改标成美元。

`ExchangeRules.convert` 用十进制乘法，最后一步按目标币种精度做 `HALF_EVEN` 舍入。JPY 为零位，KWD 为三位，计算不经过浮点数。用户可以修改实际结算金额；实际值减去按汇率计算的金额作为差额展示，不自动制造另一笔收支。只有明确点击使用当前手动汇率或重算才会更新输入；编辑旧账不会因全局汇率变动重算。保存后，分录只使用记录内的实际值。

手续费是额外从现金账户扣除的非负金额：支出/转出增加扣款，收入/到账减少净增加；借贷费用扣现金而不减少本金。余额调整不接受手续费。费用用现金账户实际币种，切换币种后已有费用需要重新确认，不能按新币种静默解释旧数字。统计与预算应独立计费用，不把转账或本金当普通消费。

未提交草稿另外保留汇率币种对、实际金额币种及手续费币种。若离开编辑页后更改了尚无交易历史的账户币种，恢复草稿不会把旧汇率或旧金额换一个币种标签后保存；必须重新确认对应输入，或重新选择已变更的同币种账户。

切换账单类型、账户或名义币种造成金额币种变化时，清空名义金额并要求重新输入，不把旧数字按新币种保存。重复选择当前币种不会改动草稿；支出与待报销之间切换且结算账户、币种未变时，保留已确认的实际金额、汇率和日期。

余额历史按交易日期汇总所有账本的有效分录，期初余额为基线，支持指定时刻的快照；完整重建值与账户当前余额一致，包括已登记的未来日期交易。修改或补录旧账会重建历史，删除及撤销会相应移除或恢复影响。账户没有历史开户时间，因此期初基线不是账户在任意更早日期确已存在的证明。历史以账户本币展示，不声称拥有历史市场汇率。接口提供逐日余额与净变化序列，C5 统计继续复用真实分录。

逐日净变化使用无损大整数汇总，即使一天内的变化超过单笔金额范围也可完整显示；某个历史时点的余额本身超出当前金额模型范围时明确显示加载错误，不截断或显示为零。

静态参照只确认原版 `CurrencyExtra` 的源/目标/基准币及手续费字段、`CurrencyManageAct` 的汇率入口、`AssetTrendAct` 的历史入口与服务限制。这里独立实现精确金额与本地重建，不复制原浮点计算或试用/服务端行为。
