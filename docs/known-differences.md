# 已知差异与边界

本文是最终整体验收的差异清单，不以功能实现或测试类名代替运行证据。当前实际状态见 `full-coverage.json` 和项目 `outputs/验收报告.md`。

## 有意的产品差异

- 独立 Kotlin / Compose Material 3 应用，不修改重签原 APK，不冒充钱迹官方。使用本地 UUID、独立包名和签名；不能直接覆盖原版私有数据库。
- 不接原版登录、账号、会员、云同步、多人协作、在线反馈或实时汇率。多币种采用手动汇率与历史实际成交快照；没有汇率时明确报告缺失，不直接相加。
- 不接生成式本地/云端 AI，不下载模型。预留增强接口默认返回不可用；已批准的中文 OCR 使用随 APK 打包的本地图像识别 SDK，与生成式 AI 提供方分开。
- 界面按 M3/Material You 重组，不作旧版像素复刻。账户在本地账本之间共享，分类属于具体账本，分类最多两层。父分类归档会连同子分类，恢复父分类不默默恢复所有子分类。
- 退款按发生期冲减支出，超出原始消费的部分作为退款收入；完整历史关联用于分类。报销垫付/收回与借贷本金不重复算普通收支；利息和手续费单列。预算排除与统计排除互相独立，删除复制预算保留删除标记。
- 周期默认生成待确认草稿，自动入账必须明确选择。后台采用平台调度并在回到前台补执行，不能承诺精确到点唤醒；稳定执行 ID 防止补执行/重启重复入账。分期按整数余数分配，总额不损失。
- 自动识别当前窗口未处理时，新候选排队而不是丢弃。识别、等待、忽略、失败和已保存分开统计；只有成功保存才变余额。相似候选允许人工判断，跳过去重不等于静默付款或保存。
- 批量编辑目前处理分类、备注、标签及两个排除标记，不进行不透明的批量金额/账户变换。批量删除与撤销是整体事务；24 小时内且所有成员未被后续修改才可撤销。被历史批量快照引用的账户币种/类型/期初余额及分类方向也受保护，过期不会使历史备份失效。
- 完整 ZIP 备份未加密，同 ID 冲突不静默覆盖；覆盖前保留一个私有恢复快照。历史图片引用保留，暂不自动清理孤立私有附件。系统自动云备份与设备转移关闭，手动选择的外部文件服务可能自行同步。
- 标准 Android 小组件是本期实现，不冒充厂商专有组件。隐私模式中，即使应用已解锁，小组件仍隐藏账本名和金额，悬浮财务窗口仍不显示。

## 外部兼容证据

- 七个包、56 个静态连接支付场景有独立合成正反样本。真实第三方支付 App 场景验证数仍为 **0**，不将 56/56 样本测试宣传为现实兼容率。第三方版本、受限节点、密码页和系统安全限制均不能绕过。
- 独立美团外卖新增两个本地开发规则，单独授权，不计入原版 56 个静态场景。实际页面与发布边界见 `recognition-meituan-takeout.md`；不能把开发接入或模拟器合成页面测试称为真机实单兼容。
- OCR 有实际离线模型执行和自制图像样本证据，但没有广泛真实收据、手写或所有支付截图版本的准确率测量。未知金额、币种冲突和未知时间不编造字段。
- CSV、XLSX、JSON 的 OMyMoney 自有格式均实现并验证读回。原版第三方平台列表和解析在原服务端，未连接原服务器；不能宣称支持其全部导入平台。
- 钱迹表头契约仅有自制的支出、收入、转账、信用卡还款四类样本；涉及原版折扣、附件、报销扩展等未有真实样本的字段会被明确阻止，不默默丢弃。详见 `data-exchange.md`。
- 官方 API 26/34/36 模拟器与实际 TalkBack/系统 UI 检查的具体结果在报告中。没有指定目标物理手机、厂商后台环境或完整生物识别硬件矩阵，不能写成“所有现代手机均可用”。
- 用户明确取消后续 TalkBack 验收，不再作为本次交付门槛。已保留无障碍标签和普通键盘测试，但真实 TalkBack 流程仍未核实，不计为通过；测试临时修改的系统设置已恢复。

## 已知小问题

1. 悬浮内嵌时间编辑对普通格式错误和夏令时缺口共用提示。
2. 悬浮分钟级时间编辑确认后原有秒数归零；核对比较会显示秒数。
3. OCR 图片队列主要显示序号而非缩略图/文件名，旋转反馈主要显示角度文字。
4. OCR 存储异常借用“更新设置失败”提示，错误可见但文案不够准确。
5. 匹配账单超过 10,000 笔时，“全选”只取前 10,000，但全选勾选状态仍与完整集合比较；实际已选数量为准，未筛选列表的上限提示也需改善。
6. 导入映射表先展示较多内部字段名，尚未把未解决账户/分类映射优先排列或收起不常用列。

这些问题不隐藏，也不以“大部分通过”抹去。发生严重写入/解析错误时保留既有账目和输入；是否可再次执行以当前状态和明确错误为准。公开分发或商店上架的许可/政策审查未作为本次个人本地交付的已完成事项。
