# 本地统计口径

统计以当前账本为范围，使用该账本时区的月度或年度半开区间。最大 366 日；年度包含 12 个自然月，闰日按实际日期保留。当前账本、统计周期及起止日期可见，账户、分类、经济类型、标签和备注筛选同时作用于所有统计视图。

## 同一份数据

`StatisticsCalculator` 先读取当前账本完整有效历史，由 `EconomicFacts` 分类，再应用日期与用户筛选。不能先删掉区间外的退款来源或更早退款，否则会改变本期退款的冲减上限。

- 收入：普通收入、利息收入及超出原支出的退款收入。
- 支出：普通支出、利息支出、独立手续费；退款在退款日形成负支出，沿用来源分类。
- 转账：转账和信用卡还款的独立合计，不计入收入、支出或收支结余。
- 借贷本金、报销垫付及回款、余额调整不形成普通收支；这些交易的手续费仍计支出。
- 每条记录自身的“不计统计”决定是否纳入；“不计预算”不影响统计。
- 账户筛选匹配交易的任一端，并保留该交易对应的经济贡献。这里不是该账户的净现金流报表；资产变动在资产历史查看。
- 选择父分类包括其子分类。分类分布仅列直接归属，不把父级合计和子级再次相加。转账手续费及无来源分类的收入单列未分类。

每项经济贡献只折算一次。汇总、趋势、日历、年度月表和统计明细都从这些已折算贡献产生，不各自重复舍入或重新筛选。退款及手续费在统计明细单独标明，点击可查看原始账单。原始账单列表仍展示交易本身，不将它的名义金额总和冒充收支汇总。

## 币种与数值

优先使用与账本币种相同的名义金额，否则使用账单已保存且币种匹配的实际金额，否则使用明确的当前手动直达汇率。没有自动倒数或交叉汇率，没有联网定价。采用 HALF_EVEN，保存实际金额不随手动汇率重新定价；使用的手动汇率与日期在概览可见。

缺少汇率只使受影响的汇总组变为未知，界面列出缺失币种，不把外币最小单位与本币相加，也不冒充零。无记录的日/月为零。累计值使用 `BigInteger`，可超过单条账单的 `Long` 限制。收支结余为收入减支出，任一未知则结余未知。

## 展示与证据边界

收支趋势的纵轴和单位明确，收入为实线圆点，支出为虚线方点；缺少估值的日期断线。逐日或逐月数据表提供精确值，不要求只凭颜色读图。分类使用有零点的带符号横条，不给负退款画百分比饼图。日历在窄屏、大字体或低高度横屏时改用可点选的日期列表。日期行明确标注经济类型，显示所选类型金额，未选类型时显示支出；点击后仍展示当天全部汇总。低高度趋势将图例、坐标与绘图区横向排列，不要求在被遮住的上下半幅之间猜测曲线。

筛选、周期及滚动位置在账本间分别保存，并支持详情返回与 Activity 重建。只有真实的页签、周期或筛选变更才重置滚动，加载占位不覆盖已保存的位置。年度日历可以浏览该年月份；年度汇总口径不会因日历月份切换而偷偷改变。预算与筛选保留在账本顶部工具栏的固定入口。

核心测试覆盖统一筛选、跨时区边界、闰年、独立排除标记、历史退款、缺汇率、单次舍入、空数据和超大累计值。原生 UI 测试覆盖统计视图一致性、明细返回、年度汇总、筛选重建与账本隔离、缺汇率、空月、负退款和超大金额。实际设备、TalkBack 朗读及平台兼容范围另见最终验收，不能由 Compose 语义测试推断已验证。
