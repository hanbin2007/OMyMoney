# 离线截图识别

## 输入与结果

设置的截图识别入口使用系统文件选择器；图片分享通过普通 `ScreenshotImportActivity` 接收。每批最多 10 张 PNG、JPEG 或 WebP，用户明确点击识别后才处理。图片逐张识别，成功入队、失败和中止分别显示；核对按钮打开主应用里已经存在的队列项，不接受外部账单字段。

图片 URI 必须为 `content:`，读取遵循 Android 的实际 URI 权限。外部分享文本不作为指令处理，其他 extras 不能初始化编辑器或 SavedStateHandle。选择、旋转和已入队 ID 可跨 Activity 重建保留，进程恢复不自动重新识别中断图片。重复处理同一导入项使用稳定提交 ID，避免队列已提交而 UI 状态尚未保存时重复入队。

源图片不自动变成附件。不申请持久 URI 权限，不保存整页 OCR 文字；只有受限、脱敏字段依据进入队列。识别中的私有缓存文件在完成、异常或取消后删除，进程被杀留下的 `.image` 文件在应用下次启动时清理。

## 模型与资源边界

- 固定依赖为 `com.google.mlkit:text-recognition-chinese:16.0.1`，不是 `play-services-mlkit-text-recognition-chinese` 动态模型。中国字形与拉丁字形模型资产和四种 ABI 的 OCR 原生库已在 APK 内核对。
- 构建时从依赖仓库获取 SDK，不代表运行时需要下载模型。依据为 [Google 官方 Android 文字识别文档](https://developers.google.com/ml-kit/vision/text-recognition/v2/android)；依赖校验值随工程提交。
- OCR 使用打包的本机模型，未接入原版后端、远程 OCR 或模型服务。0.2 起 Manifest 为独立诊断和 APK 更新声明 `INTERNET`；上游 ML Kit 可能发送 SDK 指标，因此不能再把离线 OCR 等同于整个 APK 无网络能力。
- 输入限制 20 MiB、3200 万像素、单边 16384 像素；先读边界，解码到不超过约 3072 像素的边长。处理 EXIF 方向及用户显式 90 度旋转。
- OCR 输出限制 1024 行、每行 4096 字符、总计 65536 字符并校验坐标。图片读取和识别不在主线程执行，整个进程只有一个原生识别任务在执行。
- 取消会关闭阻塞的 provider 输入流。已经交给不可取消的 ML Kit 任务的 bitmap 和执行许可由任务完成回调释放，不在原生任务仍读图时提前 recycle；迟到结果不会继续入队。

## 规则范围

`ScreenshotReceipt` 只处理显式支付/付款/收款/转账或待付款状态及金额标签；`ScreenshotUnknown` 产生待人工输入的部分草稿。实际付款标签优先于原价和优惠，冲突金额留空，笼统“交易成功”不推断收支方向。时间必须有完整日期和时间，今天、订单创建时间和识别时刻不代替交易时间。相邻字段按同一行或有界下方坐标关联，不取远处最大的数字。

失败交易拒绝，待付款和退款处理中始终待核对；账户不自动选择，任何结果都不直接入账。模板包含字段依据，不代表 OCR 每次都读对。实测两行合成图片中模型曾把“实付金额”读成“实付金額颜”，该结果保持金额未知，并加入纯规则反例；没有为了让测试通过而增加模糊纠错。

## 验证

- `ScreenshotRulesTest`：实付款、优惠、多金额、未付款、退款、未知格式、笼统交易方向、缺时间、几何边界、空白和模型误字。
- `ScreenshotImportTest`：真实打包中文模型、空图、失效 URI、外部网络 URI 拒绝、超大图、EXIF 旋转、阻塞流取消与缓存清理。
- `ScreenshotPipelineTest`：十张顺序入队且余额不动、超限明确拒绝、失败和取消独立状态、分享边界、提交后重试的稳定身份。
- `ScreenshotShareTest`：真实分享 Activity、恶意 extras 隔离、明确开始前不识别、配置重建保留输入。
- `ScreenshotUiTest`：图片进入真实 OCR 队列，核对按钮在冷启动主应用打开相应草稿。测试发现并修复导航图尚未就绪的冷启动问题。
- 专用 API 34 模拟器已开启飞行模式并关闭 Wi-Fi/数据，清除本测试应用数据后运行四项 OCR 测试。断言系统没有活动默认网络、APK 未声明网络权限，首次模型识别通过。360dp 浅色、600dp 深色和 200% 字体的导入及草稿核对流程均通过并检查截图。

上述是合成图像和指定模拟器证据，不是第三方支付应用全模板支持率、真实照片准确率或其他 Android 版本验收。原版 56 项无障碍场景计数不包含这两个截图模板。
